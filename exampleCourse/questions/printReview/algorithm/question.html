Consider the following Python function. Each list access and arithmetic operation takes constant time.

Give the tight asymptotic bound in terms of $n=\operatorname{len}(\texttt{values})$.

What is returned for values = [1, 2, 3] ?

The inner statement executes $n(n-1)/2$ times. For the given list, the three pair sums are $3$, $4$, and $5$.
