Example 2: counter-type="full-text"Back to Top

Setting counter-type="full-text" will hide the column of options. The dropdown list next to each statement will contain the inner text of each option, rather than a counter. Setting max-response-per-option ="1" min-response-per-option ="1" ensures that each option can only be selected once.

Example 3: blank="false"Back to Top

blank="false" removes the blank first entry in the dropdown list, setting the default selection to the first option.

Example 4: number-statements and number-optionsBack to Top

number-statements and number-options determine how many statements and options are shown. Statements are sampled at random. The options will always include each correct match for the sampled statements, plus random distractors.

Canada United States Mexico France Tijuana Toronto New York City
Example 5: None of AboveBack to Top

If number-options is smaller than the amount of options required to match the sampled statements, None of the Above will be added.

Example 6: Other counter-typesBack to Top

The counter-type attribute indicates how options are identified. It can be set to lower-alpha (a, b, c, ...), upper-alpha (A, B, C, ...), or decimal (1, 2, 3).

Example 7: Complex OptionsBack to Top

Options can be added manually if they require more than simple text (e.g., images, equations or formatting). In that case, the name attribute of each pl-option must match the corresponding match attribute of the appropriate pl-statement.

$\phi$ $e$ $i$ $\cfrac{1+\sqrt{5}}{2}$ $ \displaystyle \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^{n}$ $\sqrt{-1}$
Example 8: PrairieLearn element in optionsBack to Top

HTML formatting and other PrairieLearn elements can be used inside statements and options. If used in options, an explicit pl-option must be defined with a name attribute matching the corresponding match attribute of the appropriate pl-statement.

list(filter(lambda item: item > 0, lst)) list(map(lambda item: item * 2, lst)) list(itertools.product(lst1, lst2)) [item for item in lst if item > 0] [item * 2 for item in lst] [(a, b) for a in lst1 for b in lst2]

Example 12: radio-matrix Ungraded SurveyBack to Top

The radio-matrix style is ideal for constructing ungraded survey questions.

  • You can use builtin-grading="false" to disable the grading.
  • allow-blank="true" permits students to submit without selecting an option.
  • Furthermore, you can use preset-options="agreement-5" to use predefined Likert agreement-5 options.
  • When repeat-header="1,3" is set, the radio-matrix repeats the options header in a repeating "header, 1 row, header, 3 rows" pattern.
  • Setting reset-button="true" adds a reset button to the element.

Example 13: radio-matrix Ungraded Ranking SurveyBack to Top

The radio-matrix style is also ideal for constructing ungraded ranking survey questions.

  • You can use builtin-grading="false" to disable the grading.
  • allow-blank="false" means students must choose an option per row.
  • Setting reset-button="true" adds a reset button to the element.
  • Setting max-response-per-option="2" invalidates the submission if a column is selected 3 or more times.
  • Setting min-response-per-option="1" invalidates the submission if a column is left unselected.

Please rank the following departments based on your interests

Engineering Marketing HR Advertising Top choice Neutral Not considered
Example 14: radio-matrix Graded Ranking QuestionBack to Top

The radio-matrix style is also ideal for constructing graded questions with limited selection per row or column.

  • Setting reset-button="true" adds a reset button to the element.
  • Setting max-response-per-option="1" invalidates the submission if a column is selected 2 or more times.
  • Setting min-response-per-option="1" invalidates the submission if a column is left unselected.
