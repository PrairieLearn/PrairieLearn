The examples below showcase the different features of pl-big-operator-input. Every example has allowed-blank="all" so that you can test one at a time.

Sums and Products

Submit $\displaystyle \sum_{k=1}^{n} k^2$.

Submit $\displaystyle \sum_{k\in N} \frac1{k^2}$.

Submit $\displaystyle \prod_{k=1}^{4} k$.

Integrals

Submit $\displaystyle \int_{0}^{1} x^2\,dx$.

Submit the integral in $\displaystyle \Gamma(z) = \int_{0}^{\infty} t^{z-1} e^{-t}\,dt, \operatorname{Re}(z) \gt 0$.

Submit $\displaystyle \oint_{\gamma} \frac1z\,dz$.

Submit $\displaystyle \int_{0}^{\pi} \sin(\theta)\,d\theta$.

Suprema

Submit $\displaystyle \min_{x \in \{-2, 1\} } x^2$.

Submit $\displaystyle \max_{x \in \{-2, 1\} } x^2$.

Sets

Submit $\displaystyle \bigcup_{k \in \{1,2\} } \{\cos(\pi k)\}$.

Submit $\displaystyle \bigcap_{k \in \{1,2\} } \{k\}$.

Submit $\displaystyle \bigsqcup_{k \in \{1,2\} } \{k+1\}$.

Limits

Submit $\displaystyle \lim_{x \to 0^+} \frac{\sin x}{x}$.

Submit $\displaystyle \lim_{x \to 0} \cos(x)$.

Submit $\displaystyle \lim_{x \to 0^-} \frac{1}{x}$.

Custom

Submit $\displaystyle \mathop{ \Huge\bigstar{} }\limits_{j=1}^{4} j^2$.

Submit $\displaystyle \mathop{ \operatorname{eval} }\limits_{x \to 0} f(x)$.
