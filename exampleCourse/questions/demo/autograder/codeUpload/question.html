This is a demo of using the Python autograder with a file upload interface. The autograder grades files named student_code*.py by default. If the student's uploaded filename is different, set student_code_pattern in the ConfigObject in tests/test_student.py. Here we set it to fib.py to match the file upload.

The Fibonacci numbers are 1, 1, 2, 3, 5, 8, ..., where each number is the sum of the two before it. These are numbered $F_1, F_2, \ldots$, and \[ F_n = F_{n-1} + F_{n-2}. \]

Write a Python function fib that takes a number n and returns the nth Fibonacci number, $F_n$.
