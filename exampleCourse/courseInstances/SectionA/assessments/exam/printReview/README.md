# Print review exam

This 19-question, 95-point exam combines 11 purpose-built questions with eight existing examples. It is intended for reviewing printable student copies, answer keys, Word exports, and booklets; it is not a single-subject exam.

## Content coverage

| Questions | Content                                                                                 |
| --------- | --------------------------------------------------------------------------------------- |
| 1–3       | Randomized numbers, integers, units, strings, symbolic math, and matrices               |
| 4         | Four equally sized SVG image choices, with randomized order                             |
| 5         | Python code listing, asymptotic notation, and an integer answer                         |
| 6         | A three-part case study with tables and captions spanning multiple pages                |
| 7–11      | Random checkbox subsets, photographic choices, dropdown choices, matching, and ordering |
| 12–14     | A generated plot, a directed graph, and matrix input                                    |
| 15–16     | Written argument and code response, with model answers                                  |
| 17–19     | Graph sketch, block diagram, and image/file response tasks adapted for paper            |

## Review setup

1. Load the example course from disk and open **E99: Print review: kitchen sink** in SectionA.
2. Open **Print**, create a preview, and add two assessment instances for forms A, B, and C.
3. Enable the grading table. Keep the default cover and academic integrity pledge enabled to exercise the assessment's custom honor code.
4. For each form, use **A full page** spacing for questions 15, 16, 18, and 19. Leave other questions on **Automatic**.
5. Inspect both student-copy and answer-key previews. The three review badges for code, drawing, and uploads are intentional; all questions should be included.
6. Download a student PDF, answer key, and Word file. Download a six-student booklet to check the sequence A, B, C, A, B, C followed by all three answer keys.

Check image-choice sizing, math and code formatting, continued question 6, pencil-friendly response areas, cover grading lines, and page QR codes. Word pagination may differ from PDF pagination.
