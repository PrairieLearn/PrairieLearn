# Printable exams

Use **Print** on an assessment's **Questions** page to prepare paper copies of an exam. PrairieLearn creates an assessment instance for each form, so randomized questions can differ between forms. You can preview student copies and answer keys before downloading them.

## Prepare forms

1. Open the assessment's **Questions** page and select **Print**.
2. Choose a paper size and the amount of space to reserve for written work. You can adjust the spacing for individual questions later.
3. Select **Create preview**. For an assessment with randomization, use **Add assessment instance** to make more forms. Forms are labeled A, B, C, and so on.
4. Select each form to inspect its questions. You can exclude a question from a form or change its spacing. Select **Update preview** after making changes.
5. Use **Student copy** and **Answer key** above the preview to check both versions. Review every form before downloading.

Question spacing is a minimum. If a question needs more room than the selected block, it uses the space it needs and moves to the next page when it cannot fit in the remaining space.

You can add up to 26 forms. **Regenerate Form** replaces that form with a new randomized instance. After regenerating, review its questions, exclusions, and spacing again. Printable forms are not currently supported for group assessments.

### Cover pages

The default cover includes **Name** and **Date**. Under **Additional student information**, enter one extra label per line if students should fill in other details. You can also include a grading table and an academic integrity pledge. The pledge uses the assessment's honor code when one is configured.

You can upload PDF cover pages to place after the default cover and before the questions. If you turn off the default cover, uploaded pages come first. Uploads can contain up to 10 PDFs, 100 pages total, and 10 MB total. They stay in the current browser tab until export, so add them again after reloading the page.

### Review questions

**Review printability** flags are suggestions. Check the preview for figures, instructions, and enough room for responses. A question marked **Omitted** could not be rendered; fix it or deselect it before downloading. Downloads become available once the current preview is ready and all included questions render.

Expandable `<details>` sections in questions print in full inside bordered boxes, whether they were open or closed online. Review their contents along with the rest of each question.

## Download files

Open **Download** after reviewing the preview:

| Download                                        | Contents                                                                                                                                                        |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Form A (PDF)**, and similarly for other forms | One student copy of that form.                                                                                                                                  |
| **Form A Word (.docx)**                         | An editable student copy. Uploaded cover pages are not included. Formatting and page breaks may differ from the preview and across Word applications.           |
| **Form A answer key (PDF)**                     | The answer key for that form.                                                                                                                                   |
| **All forms (PDF)**                             | One student copy of each selected form.                                                                                                                         |
| **Booklet PDF**                                 | Enter the number of students. Complete student copies cycle through the forms in order, followed by one answer key for each form. Print this file single-sided. |

If you use custom cover pages, download the booklet to inspect every student copy with its uploaded pages. Check the final downloaded files before printing or distributing them.
