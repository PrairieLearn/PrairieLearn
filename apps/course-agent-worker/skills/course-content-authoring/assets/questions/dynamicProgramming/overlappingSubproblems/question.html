A recursive algorithm computes the same subproblem many times. What does memoization do to avoid this repeated work?

Stores each computed result and reuses it when that subproblem occurs again. Always selects the locally best choice without considering alternatives. Recomputes each subproblem using a different random seed. Removes every recursive call without storing intermediate results.

Memoization caches results by subproblem, so repeated calls can reuse an existing answer.
